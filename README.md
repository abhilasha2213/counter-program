# Counter Program

A simple beginner-friendly counter application built using HTML, CSS, and JavaScript.

## Features
- Increase the counter value
- Decrease the counter value
- Reset the counter to zero
- Interactive buttons with hover effects

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Use the Increase, Decrease, and Reset buttons to interact with the counter.

## What I Learned
- HTML structure and element IDs
- CSS selectors, styling, and hover effects
- JavaScript DOM manipulation
- Handling button click events
